# Fashion Ecommerce Design System
Reference Inspiration: Khazanay.pk

This document defines ONLY the visual language, layout behavior, UI patterns, spacing, typography, motion, and styling system.

The goal is NOT to clone the reference website directly.
The goal is to redesign the existing clothing ecommerce website using the same premium visual philosophy, interaction patterns, and modern aesthetic.

---

# DESIGN PHILOSOPHY

The interface should feel:

- Minimal
- Premium
- Editorial
- Fashion-focused
- Clean
- Spacious
- Modern
- Smooth
- High-end

Avoid:
- Heavy borders
- Bright gradients
- Crowded layouts
- Oversaturated colors
- Cheap ecommerce aesthetics
- Overly rounded cartoon UI

The design should resemble a modern luxury streetwear or curated thrift-fashion brand.

---

# GLOBAL DESIGN RULES

## Layout Width

Desktop container:
- max-width: 1440px

Content width:
- 1280px

Reading width:
- 720px

---

# SPACING SYSTEM

Use generous whitespace.

Base spacing scale:
- 4px
- 8px
- 12px
- 16px
- 24px
- 32px
- 48px
- 64px
- 96px

Sections should breathe heavily.

Never stack elements too tightly.

---

# BORDER RADIUS

Use soft modern corners.

Rules:
- Small UI: 8px
- Cards: 16px
- Large sections: 24px
- Buttons: 9999px for pill buttons

Avoid sharp corners.
