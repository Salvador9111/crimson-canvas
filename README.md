# 🛍️ Uclothes

### Modern Fashion E-Commerce Platform

**Crimson Canvas** is a modern fashion e-commerce web application designed around a clean, premium, and editorial shopping experience. The project combines a responsive React frontend with Supabase-powered backend services to provide a complete foundation for an online fashion store.

🔗 **Live Demo:** [Crimson Canvas](https://crimson-canvas-lovat.vercel.app/)

---

## ✨ Features

* 🛍️ Modern fashion-focused e-commerce interface
* 📱 Fully responsive design
* 🔎 Product browsing and navigation
* 🛒 Shopping cart experience
* ❤️ Wishlist functionality
* 👕 Fashion-oriented product presentation
* 🔐 Supabase integration
* ⚡ Fast Vite development environment
* 🎨 Tailwind CSS styling
* 🧩 Reusable UI components
* 📊 Product and application data management
* 🌙 Modern, minimal visual design
* ✅ Form validation and structured user interactions
* 🧪 Testing with Vitest

---

## 🎨 Design Philosophy

Crimson Canvas follows a **minimal, premium, editorial fashion aesthetic**.

The interface focuses on:

* Clean layouts
* Generous whitespace
* Strong product imagery
* Minimal visual clutter
* Modern typography
* Subtle animations
* Responsive layouts
* Consistent component design

The design system uses a mostly monochrome palette with a restrained gold accent to maintain a high-end fashion aesthetic.
